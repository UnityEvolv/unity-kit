First public release of unitykit on npm: buttons, badges, icons and brand marks; alerts,
toasts, cards and stats; form primitives including combobox and file dropzone; overlays,
dropdowns and tooltips on Radix; adaptive tables with pagination; app shell navigation
with tabs, breadcrumbs, accordions and a stepper and wizard; avatars, loading and empty
states; and the UnityEvolv theme with generated tokens. Versions stay on 0.x until the
component API settles; breaking changes bump the minor while on 0.x.
